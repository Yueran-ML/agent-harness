# Pictures

The pictures in this directory are fan art of Columbina, a character of *Genshin Impact*.
The author of this project made them with an AI image generator, ChatGPT. They are not
official artwork.

| File | What it shows |
|---|---|
| `columbina-wings.png` | A winged figure before a full moon, above ruins that stand in still water. |
| `columbina-ruins.png` | The same figure at rest among the ruins, with a small light between her hands. |
| `columbina-storyboard.png` | Twelve small scenes with the name of the project and a mark for it. |

Each file is kept byte for byte as the generator wrote it. It carries Content Credentials
(C2PA) that name the generator and say that the picture was made by AI. Cutting a picture
or saving it in another format would take those away, so the README of the project shows
the files as they are.

The words in the storyboard belong to the picture. They are no list of what the program
does.

of a fan. It is not affiliated with HoYoverse and not endorsed by it.
