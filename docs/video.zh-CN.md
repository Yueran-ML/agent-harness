# 视频剪辑

Columbina 有两处剪视频的地方，共用同一个工程：桌面应用的剪辑工作室供人手动剪，Agent 的视频工具（以及命令行的
`columbina video`）供 Agent 剪。两边都经过 `columbina-engine`，工程、剪辑规则、撤销历史、播放和导出都由引擎管理。
一边做的修改另一边马上能看到，任何一边都能撤销另一边的最后一步。
Python 负责转录分析和可编辑的文稿，不拼接 ffmpeg 滤镜图，也不另外渲染一份影片。

## 准备

- Windows。引擎目前只支持 Windows，剪辑工作室、视频工具和 `columbina video` 也因此只能在 Windows 上使用，macOS 之后会加入。
  在 macOS 和 Linux 上，桌面应用的工作室入口变灰并说明原因，不提供视频工具，`columbina video` 的每个命令都会说明这一点；
  Agent 的其他功能照常可用。
- 桌面安装包自带引擎。在桌面应用之外使用 Agent 和命令行时，将 `COLUMBINA_ENGINE` 设为已安装引擎的绝对路径，
  或将 `columbina-engine` 放入 PATH。引擎须位于工作目录之外；视频插件的 `engine` 配置也可指定它。
  参阅[协议 2](../engine/PROTOCOL.md)。源码构建需配置 FFmpeg 开发库，在 `engine/` 目录运行 `cargo build --release -p columbina-server`。
- 引擎需要配套的 LGPL FFmpeg 动态库。导出使用显卡的硬件编码器（NVENC、Quick Sync 或 AMF），没有时改写 ProRes。
  系统中的 **ffmpeg 和 ffprobe** 只用于提取转录音频和检测静音，成片由引擎导出。
- 本地转录需另行安装 faster-whisper，并将 `COLUMBINA_WHISPER_MODEL` 指向已下载的模型目录。程序不会自动下载模型。
  也可用 `transcribe --words FILE` 读取已有词级时间标记：JSON 数组，每项包含 `start_us`、`end_us`、`text`。
- `COLUMBINA_VIDEO=1` 启用 Agent 的视频工具。语音识别在本机运行。为转录提取的音频在保存词之后（或转录失败时）删除，
  `analysis/` 只保留每个素材的词和静音信息。

## 剪辑工作室

在桌面应用侧栏点“工作室”，打开当前项目文件夹的工作室。它的工程是该文件夹里的 `.columbina/studio`，
也就是 Agent 默认使用的那个工程。工作室按 DaVinci Resolve 设计：页面、快捷键、鼠标手势和界面用词都与达芬奇一致，
并对照过《DaVinci Resolve 20 参考手册》。顶部有三个页面，也可以在页签上用左右方向键切换。

**媒体。** 媒体池，含主素材箱和可以层层嵌套的素材箱。“导入”把文件加进当前素材箱；文件留在原处，媒体池只记下它们。
素材可以按列表或缩略图显示，“素材详情”给出所选素材的编码、尺寸、旋转、帧率、位深、时长、采样率、声道、路径和入出点。
F2 重命名，Delete 从媒体池移除（有时间线在用时会被拒绝），拖动可把素材移到别的素材箱。双击素材，把它载入源检视器。
对于难以定位的素材（手机和摄像机录的那类：超过 1080p、高于 8 bit、HEVC 或 AV1、带 B 帧），引擎会生成 Proxy；
检视器标明当前显示的是 Proxy、原片还是两者混合，“使用 Proxy”可以关掉它。导出始终读原片。

**剪辑。** 剪辑时间线的页面：左侧是媒体池和特效库，中间并排两个检视器（源检视器和时间线检视器），右侧是检查器，
下方是时间线。窗口较窄（例如旁边展开着对话）时只显示一个检视器，可以在两者间切换，各自保留播放位置。
最后点过的那个检视器接收播放和入出点的按键。顶栏用来选择时间线、新建时间线（名称、尺寸和帧率，缺省取媒体池里第一个视频的设置）
和打开检查器。

- **工具。** 选择模式（A）、修剪编辑模式（T）和刀片编辑模式（B），吸附（N）和链接选择（Ctrl+Shift+L）。
  选择模式下拖动片段即移动，拖动边缘即修剪，两个片段之间 2 像素的接缝用于滚动剪辑点。
  修剪编辑模式下拖边缘做波纹修剪，在片段上半部分拖动是滑移，在下半部分拖动是滑动。刀片在点到的轨道上切开，按住 Shift 则切开所有轨道。
- **拖动。** 把片段拖到别的片段上即覆盖，移动时会用红色斜纹标出将被覆盖的帧。按住 Shift 只换轨、不改时间；
  按住 Ctrl+Shift 做洗牌插入，其他片段让位；按住 Alt 在落点留下一份拷贝。片段换到别的轨道时，
  与它链接的片段在各自同类的轨道上移动同样的轨数，与达芬奇的 Linked Move Across Tracks 一样：
  画面从 V1 移到 V2，链接的声音也从 A1 移到 A2。不会为此新建轨道：没有对应的轨道时什么都不移动，并说明原因。从媒体池拖入的素材缺省覆盖；
  按住 Ctrl+Shift 为插入，按住 Shift 只放声音，按住 Alt 只放画面。拖动过程中按 N，只对这一次拖动切换吸附。
- **三点编辑。** F9 至 F12 以及 Shift+F10、Shift+F12 按达芬奇的三点编辑规则把源检视器里的素材放上时间线：
  依据源的入出点（未设时取首帧和末帧）、时间线的入出点或播放头，只设了出点时向前回推。
  轨道头选择画面和声音的目标轨道，也可以锁定、静音或隐藏轨道。
- **检查器。** 视频轨上的片段可调缩放、位置、旋转角度、不透明度和淡入淡出；音频轨上的片段可调音量、声像和淡入淡出；
  标题可改文本、大小、颜色、位置和对齐；纯色可改颜色。数值可以直接输入，也可以左右拖动（按住 Shift 变化快十倍），
  松手时提交一次；Esc 撤回，双击标签恢复缺省值。选中多个片段时只显示它们共有的字段。
  选中转场时显示类型、时长和对齐方式；素材余量不够时，检查器给出放得下的最长时长。什么都没选时显示时间线设置；
  时间线一旦有内容，帧率即锁定。
- **变速。** R 键（或检查器里的按钮）更改所选片段的速度，范围 1% 到 10000%，可倒放，可选是否波纹移动后面的内容。
  本版本变速时声音的音调随速度改变。
- **特效库。** 把叠化、淡入淡出至黑场或白场、音频交叉淡变拖到剪辑点上，按落点做成居中于、结束于或起始于剪辑点；
  拖到已有的转场上则改变它的类型。把标题或纯色拖到视频轨上，会在落点覆盖 5 秒。

每个手势或按键都是一个事务、一步撤销（Ctrl+Z、Ctrl+Shift+Z），与 Agent 共用同一条历史。
引擎拒绝某个编辑时（轨道已锁定、有片段挡住波纹、素材余量不够做转场、期间工程被别人改过），时间线上方用一句话说明原因，工程不变。

**快编。** 快速粗剪的页面。只有一个检视器，可切换为源片段、源磁带或时间线。
源磁带把当前素材箱及其子素材箱里的全部素材首尾相接，当作一盘磁带来回浏览；上下方向键跳到前一个或后一个素材。
检视器下方有“智能插入”（插在离播放头最近的剪辑点，时间线上会标出这个点）、“追加”、“波纹覆盖”、
“放到上层”（播放头离剪辑点不超过 5 帧时放在该剪辑点）和“源覆盖”按钮，以及在最近剪辑点加转场的“叠化”和“淡入淡出至黑场”。
源覆盖按时间码对齐素材；引擎目前还不读时间码，所以这个按钮禁用并说明原因，达芬奇在没有重叠时间码时同样什么都不做。
下方是两条时间线：上面一条显示整部片子，下面一条显示播放头附近，两条都可以编辑。
与达芬奇的快编页一样，第一条视频轨有磁性：在这条轨上移动或删除片段会合上空隙，松手在剪辑点上会插入该处，
拖边缘会波纹修剪；上层轨道的片段只移动或改变长度。其他轨道上跨在空隙里的片段（例如垫底音乐，
或连同声音一起直接上移到 V2 的片段）留在原处，空隙之后的内容在所有轨道上一起前移。

**字幕。** 右键任一轨道头选“添加字幕轨道”，或用轨道头上方的“+”按指定语言添加。右键字幕轨选“添加字幕”，
或在字幕轨空白处双击，会在播放头处加一条 3 秒的字幕。拖动字幕可以移动，拖两端可以改入点和出点；
文本、起点和时长在检查器里修改。Backspace 删除字幕并留下空隙，Delete 删除字幕并让同一轨上后面的字幕前移。
与达芬奇一样，一条时间线同一时间只显示一条字幕轨：点字幕轨轨道头上的眼睛，会用这一条替换正在显示的那条。
字幕只画在时间线检视器里，不会烧录进画面。

**导出。** 剪辑页和快编页上的“快速导出”打开导出对话框：选择时间线、范围（整条时间线或入点到出点）、
编码（H.264、HEVC 或 ProRes）、质量，以及另存为 SRT 的字幕轨（每条一个勾选框，缺省勾选正在显示的那条）。
点“导出到…”选择保存位置。工作室页头下方的进度条显示已完成的帧数、速度和编码器，可以取消，完成后可以打开所在文件夹。
导出读取开始时的工程快照，期间可以照常剪辑和播放。同一时间只能有一个导出任务，包括 Agent 发起的。
已存在的影片只在保存对话框确认替换后才会覆盖；旁边已有的 SRT 或 `.mov` 不会被覆盖，导出会说明这一点。

**旧工程。** 在 Windows 上，工作室打开一个文件夹时，会在后台把工作室出现之前由 Agent 剪过的旧工程转成工作室的时间线
（见下文“旧工程迁移”）。页头的横幅列出转换了哪些、哪些部分没能转过来；旧文件保持原样。

## Agent 的视频工具

剪辑工具有九个：`video_import`、`video_info`、`video_edit`、`video_transcribe`、`video_story`、
`video_apply`、`video_correct`、`video_render`、`video_undo`。调色工具有六个：`video_grade_info`、
`video_grade_set`、`video_grade_node`、`video_grade_copy`、`video_grade_lut`、`video_grade_group`，见下文“调色”一节。默认工程是工作目录下的 `.columbina/studio`，即工作室的工程；
也可用 `project` 指定其他目录。工程里有多条时间线时，作用于时间线的工具需要指定时间线 ID。

- `video_import` 把素材加进媒体池，可以指定已有的素材箱，返回素材 ID；它不会把素材放上时间线。
- `video_info` 列出素材、素材箱和时间线，包括轨道、片段、源入出点、位置、时长、速度和转场；调过色的片段和时间线附调色摘要，并列出调色组。
- `video_edit` 把一批编辑作为**一个原子事务、一个撤销步骤**提交。回执包含已执行的操作、`$name` 对应的实际 ID，以及被夹值的输入序号。
- `video_transcribe` 把素材转录到 `analysis/`，也可以用转录的词替换一条字幕轨的字幕（一步撤销）。
- `video_story`、`video_apply`、`video_correct` 用于按文字剪辑（见下文）。
- `video_render` 导出，等待期间报告进度（见下文）。
- `video_undo` 撤销工程的最后一步，包括人在工作室里做的那一步；`redo=true` 重做。分析文件和文稿不在这条历史里。

`video_edit` 的剪辑命令与达芬奇相同：`insert`（插入）、`overwrite`（覆盖）、`replace`（替换）、`place_on_top`（放到上层）、
`append`（追加）、`smart_insert`（智能插入）、`ripple_overwrite`（波纹覆盖）、`lift`（删除并留下空隙）、`ripple_delete`（波纹删除）、
`ripple_delete_range`（波纹删除区间）、`close_gap`（合上空隙，不是达芬奇快编页里重新构图的 Close Up）、`blade`（刀片）、
`move`、`insert_move`（洗牌插入）、`trim`（修剪）、`roll`（滚动）、`slip`（滑移）、`slide`（滑动）、`set_speed`（变速）、
`add_transition`、`set_transition`、`remove_transition`、`add_track`、`remove_track`、`add_cue`、`set_cue`、`remove_cue` 和 `cues_from`。
同一批里可以混用协议的基本操作，例如 `add_timeline`、`add_bin`、`set_clip`（变换、增益、声像、淡入淡出）、`set_track`、
`set_media` 和 `set_timeline`。轨道锁定、链接和素材余量由引擎判断。时间线位置按整数帧计，源素材位置按 ticks 和 scale 计。
字段省略表示使用其默认规则，显式 `null` 表示清空该字段或关闭相应目标轨道。各命令的字段见工具说明。
带 `to_track` 的 `move` 会让链接的片段在各自同类的轨道上移动同样的轨数（Linked Move Across Tracks）；
带 `straddling="stay"` 的 `close_gap` 让其他轨道上跨在空隙里的片段留在原处，与快编页合上第一条视频轨的空隙相同。

删除时间范围时，该范围中的字幕会裁剪或删除，后面的字幕随画面前移。
在字幕中间插入片段时，字幕切成同文字的两段，后半段随原画面后移。锁定轨道保持不动。

与 DaVinci Resolve 一样，一条时间线同一时间只显示一条字幕轨。已有字幕轨显示时，`add_track` 新加的字幕轨默认隐藏。
要改显示另一条，在同一批编辑里先把正在显示的那条 `set_track` 设为 `enabled:false`，再把另一条设为 `enabled:true`；
否则引擎拒绝，错误码为 `VIDEO_SUBTITLE_SHOWN`。

### 调色

调色工具操作的是调色页的调色，结构与 DaVinci Resolve 相同：每个片段一棵节点树，每个片段组有组前置和组后置两张调色，
时间线上还有一张作用于整条时间线的调色，按这个顺序生效。工具用片段 ID 指片段的调色，
用 `{"level": "pre_clip" | "post_clip", "group": "k2"}` 指组的调色，用 `{"level": "timeline"}` 指时间线调色；
节点用调色页显示的编号（最先添加的是 1）或节点 ID 指定。每次修改是一个事务、一个撤销步骤，与工作室里的人共用；
回执附带这张调色的摘要。

- `video_grade_info` 概括一张调色：按顺序列出节点的编号、ID、类型、标签和是否启用，每个输入接自哪里，
  校色节点只列改变了画面的参数（按 `primaries.saturation` 这样的路径，用达芬奇界面上的单位），LUT 及其中缺失的，
  混合器及其输入，以及节点是否带镜头匹配的调整。不指定调色时，列出所有调过色的片段、时间线调色和调色组。
- `video_grade_set` 修改一个节点的参数、标签或 `enabled`。参数在发出前先检查，越界时用达芬奇的参数名、范围和中性值说明
  （饱和度：0 到 100，50 不改变画面）。数值参数也可以是关键帧：`{"keys": [{"frame": 0, "value": 40, "interp": "linear"}, ...]}`，
  `hold` 是静态关键帧，`bezier` 是缓入缓出。帧号的含义：素材片段是它显示的那张画面在素材里的帧号（按素材自己的帧率，从 0 起），
  所以修剪、滑移、变速之后关键帧仍在原来的画面上；标题、纯色、静帧从片段第一帧算起；时间线调色按时间线的帧。
- `video_grade_node` 用 `append`（追加节点）、`add_serial`、`add_serial_before`、`add_parallel`、`add_layer` 添加校色节点，
  可以在同一步里给出标签和参数；也可以删除、重置或取出一个节点。
- `video_grade_copy` 把一张调色复制到其他调色上（`preserve_nodes` 保留目标前 N 个节点），把它的节点追加到其他调色末尾
  （Append Node Graph），或者粘贴一个节点的全部参数或单个参数。`keyframes` 决定复制过去的关键帧放在哪里：
  `source_timecode`（默认，按素材里的同一时刻）或 `start_frame`（按离各片段第一张画面的距离）。
- `video_grade_lut` 列出工程目录和 LUT 库里的 `.cube` LUT（LUT 库为 `COLUMBINA_LUTS`，未设置时为 `COLUMBINA_HOME`
  或 `~/.columbina` 下的 `luts` 文件夹），按名字给校色节点设置或清除 LUT；不指定节点时，LUT 放在末尾新加的校色节点上。
- `video_grade_group` 新建片段组、加入或移出片段、改名、删除，把一张调色复制进组前置或组后置调色，或者把组调色并入各片段自己的调色。
  组调色的进一步修改用其他调色工具，并指定 `pre_clip` 或 `post_clip`。

引擎查找 LUT 的位置上没有这个 `.cube` 文件时，LUT 记为缺失。文件存在但解析失败的，由引擎在绘制画面时报告。

## 按文字剪辑

`video_story` 将对话轨（默认 A1）写成 `story/<时间线 ID>.md`。读取后，可用 `~~` 划掉词句或直接删除，
再用 `video_apply` 在未锁定的轨道上做波纹删除，整批是一个事务：画面、声音、标题和未锁定的字幕都随剪切移动。
文稿对应片段的实际位置，支持重复使用、修剪、变速和倒放。
不能通过移动文稿行来重排片段，也不能增加未说过的词。修改 `[pause 1.8s]` 可缩短停顿；`dry=true` 仅预览删除范围。
没有字母或数字的符号（如 `—`、`♪`、`...`）跟随同一行中最近的词：前面有词时随前一个词，位于行首时随后一个词；
只有这类符号的一行，只有在删除整行、清空或用 `~~` 划掉时才剪掉。未改动的文稿不剪任何内容。

时间线或转录已变化时，先刷新文稿：文稿按首行的摘要核对，摘要覆盖时间线、轨道和词。首行的修订号只供查看；
剪切本身只在读取时的修订号和引擎会话下提交，期间有人修改或引擎重启都会以 `VIDEO_STALE_REVISION` 拒绝。
未先运行 `video_story` 就调用 `video_apply` 时，会提示先生成文稿。
`video_correct` 只改显示文字，不改变录音，也不会自动重写已有字幕；需要重新生成字幕时，用 `video_transcribe`
指定字幕轨：该轨替换为对话轨上所有已转录素材的字幕，按时间线顺序排列，每条不晚于下一条开始时结束。

## 命令行

编辑命令返回 JSON 回执。下面的素材 ID 和轨道 ID 应替换为实际返回值：

```bash
columbina video import .columbina/studio raw/interview.mp4
columbina video info .columbina/studio
columbina video edit .columbina/studio --file edits.json
columbina video transcribe .columbina/studio m1 --subtitles TRACK_ID --language zh
columbina video story .columbina/studio
# 编辑回执中的文稿路径，然后：
columbina video apply .columbina/studio --dry
columbina video apply .columbina/studio
columbina video render .columbina/studio --codec prores --output out/cut.mov
columbina video undo .columbina/studio
columbina video undo .columbina/studio --redo
```

下面是 `edits.json`：创建时间线，并将 `m1` 放在开头。替换为导入回执中的素材 ID。
回执会把 `$film`、`$v`、`$a`、`$s` 映射为实际 ID，`TRACK_ID` 使用 `$s` 对应的值。
工程有多条时间线时，加 `--timeline ID`。

```json
[
  {"op":"add_timeline","timeline":{
    "id":"$film","name":"Cut","width":1920,"height":1080,
    "rate":{"num":25,"den":1},"sample_rate":48000,
    "tracks":[
      {"id":"$v","name":"V1","kind":"video","enabled":true,"locked":false,"clips":[],"transitions":[]},
      {"id":"$a","name":"A1","kind":"audio","enabled":true,"locked":false,"clips":[],"transitions":[]},
      {"id":"$s","name":"S1","kind":"subtitle","enabled":true,"locked":false,"language":"en","cues":[]}
    ]
  }},
  {"edit":"insert","timeline":"$film","source":{"kind":"media","media":"m1"},"at":0}
]
```

也可用 `edit --edits JSON` 直接传入数组；`story --track ID` 指定对话轨，`apply --fresh` 重写文稿。
`correct DIR MEDIA SENTENCE WRONG RIGHT` 更正一个词，句子索引从 0 开始。
旧的 `overlay` 和 `render --final` 已退役，分别改用引擎编辑命令和 `render --quality high|medium|small`。

## 导出

导出使用原素材，不使用播放用的 Proxy。`--codec` 支持 `h264`、`hevc`、`prores`，ProRes 使用 MOV。
H.264/HEVC 硬件编码器不可用时回退为 ProRes MOV，回执给出实际路径。
字幕以 UTF-8 SRT 保存在影片旁边，**不烧录进画面**；标题会绘制进画面。
和 DaVinci Resolve 的交付页一样，导出时单独选择要写 SRT 的字幕轨，显示或隐藏的都可以：
`--subtitles visible`（默认）写正在显示的那条，`--subtitles all` 写全部字幕轨，`--subtitles S1,S2` 写列出的轨
（`video_render` 工具的参数为 `subtitles: "visible" | "all" | [轨道 id]`，`[]` 表示不写）。
一条轨写成 `<影片名>.srt`，多条写成 `<影片名>.<语言或轨名>.srt`。
`--no-subtitles` 不输出 SRT，`--replace` 明确允许覆盖已有输出。
导出读取开始时的工程快照，后续编辑不会改变正在导出的影片。无论由工作室还是 Agent 发起，同一时间只能有一个导出任务。

## 旧工程迁移

```bash
columbina video migrate --workspace /path/to/workspace --json
```

扫描工作目录中三层以内尚未迁移的旧版工程，跳过 Git、node_modules 和 `.columbina`。
每个旧工程成为一条 Studio 时间线，整个迁移可一步撤销，媒体池已有素材会复用。
旧目录文件保持原样，只新增 `migrated.json` 回执；再次迁移会跳过已完成工程。
Agent 首次连接默认 Studio 时也会执行迁移；桌面应用的工作室在 Windows 上打开一个文件夹时同样会迁移，
应用运行期间每个文件夹只做一次，失败时下次打开再试。

每个旧工程单独迁移。无法迁移的工程（文件读不了，源文件移动、改变或不在会话权限内，缺少转录，引擎拒绝）
记为 `{"source", "error"}`，其余工程照常迁移，下次再试；此时命令以 1 退出。Agent 工具不会因迁移失败：
每个会话只迁移一次，最多 20 秒，结果放在 `migrations` 中，其余留给 `columbina video migrate`。
旧素材没有缓存的静音信息、而在工具中查找超过 8 秒时，其切点落在词的边界上，回执会注明。
相对路径的源文件先在旧工程目录旁查找，再在工作区查找。迁移在引擎接受后被中断时，下次运行会根据
`analysis/migrations/` 中的记录找到已建的时间线，不会重复创建。`migrated.json` 记录的时间线已不在工程中
（例如撤销了迁移）时，下次运行会重新迁移，并在 `warnings` 中说明；若不想再迁移，删除旧目录或保留该时间线。

回执列出未迁移的内容和缩短的转场。自动音乐压低及声音备注暂不迁移；淡入淡出、增益、变速、图片位置、标题和字幕时间会转换。
若源文件已变化，迁移会拒绝把旧切点应用到另一份内容上。
旧纯音频工程转换为 25 fps 时间线，旧毫秒位置换算为帧。旧 story.md 中尚未提交到 timeline.json 的编辑不会自动应用。

Agent 的源文件读取和输出写入遵守会话文件权限，包括 `add_media` 编辑添加的素材（以完整路径交给引擎）
和导出时写在成片旁的 SRT 文件。素材中的话是影片内容，不是给 Agent 的指令。
`video engine --project DIR --json` 可检查连接；最后一个客户端断开一段时间后，引擎自动退出。
